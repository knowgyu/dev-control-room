코드 변경을 맡기기 전에, 품질 상태와 근거를 한 줄로 이어봅니다.

Dev Control Room은 저장소를 대신 수정하는 화면이 아닙니다. Git·Worktree 상태와 결정론적 점검 결과를 먼저 확인하고, AI Agent나 외부 작업은 사람이 승인한 범위 안에서만 이어지게 합니다.

무엇을 하려면 어디로?

개선지금 손볼 항목과 다음 행동 프로젝트저장소·Worktree 관찰 범위 작업점검 기준과 승인된 실행 검증Quality Run·효과·근거 진단Git·품질 도구·Provider 설정 활동등록·점검·실행의 시간순 기록

Jenkins·릴리스·정리는 작업에서 계획을 만들고, 대상과 승인을 다시 확인한 뒤 실행합니다.

상황별 시작점

Jenkins·릴리스·Agent는 별도 경로입니다.

진단에서 설정을 확인한 뒤 작업에서 계획을 만들고, Worktree·revision·digest를 검토하고 승인합니다. 결과는 검증과 활동에 남습니다.
