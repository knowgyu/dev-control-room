# Decision records

Status: active

Decision records capture durable choices that would otherwise be rediscovered
from chat history or overwritten in broad implementation plans. They are short:
context, decision, consequences, and links. Supersede a decision with a new
record; do not rewrite accepted history.

- ADR-001-ai-assisted-code-assurance.md — active v1 assurance, provider,
  evidence, and cost-observability boundaries.
