# Dev Control Room v0.15.0

이번 마이너 릴리즈는 처음 사용하는 사람이 실제 작업을 끝까지 이어갈 수
있도록 `사용법` 화면을 제품의 실행 흐름에 맞춰 구체화합니다.

## 포함 내용

- 사용법을 추상적인 개념 설명에서 실제 첫 사용 순서로 바꿨습니다.
  `프로젝트 → 진단 → 개선 → 작업 → 검증 → 활동`의 화면 이동을 한눈에
  보고, 각 단계에서 누를 것과 완료 기준을 확인할 수 있습니다.
- 제품이 해결하는 범위와 사람이 결정해야 하는 경계를 분리해 설명합니다.
  Git·Worktree와 결정론적 점검은 자동 확인 대상으로, Agent·외부 작업과
  승인은 사람의 판단이 필요한 대상으로 안내합니다.
- 사용법 화면에 화면 연결 지도와 Jenkins·릴리즈·Agent를 위한 별도 경로를
  추가했습니다. 각 안내 항목은 실제 화면으로 이동하는 링크를 가집니다.
- 가이드의 슬라이드 상태를 `#guide?slide=N`으로 유지하고, 키보드 포커스·
  의미 있는 링크·ARIA 안내 영역을 함께 점검합니다.
- README, 사용자 가이드, handoff 기록과 UI 정적 계약을 현재 흐름에 맞춰
  갱신했습니다.

## 경계

- 릴리즈 산출물은 Windows amd64 portable ZIP과 `SHA256SUMS`만 제공합니다.
  arm64는 교차 빌드 검증만 하고 Linux/arm64 릴리즈 asset은 만들지 않습니다.
- 이번 릴리즈는 기존 승인·Action Broker·artifact 무결성 경계를 바꾸지
  않습니다. 사용법 안내는 실행 권한을 추가하지 않습니다.
- 가이드의 예시·설명은 저장된 효과나 비용 집계에 포함되지 않습니다.
